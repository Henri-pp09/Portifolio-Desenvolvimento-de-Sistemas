01 / A proposta

Natureza e tecnologia no mesmo lugar.

O Aviário Sonoro é um projeto educacional dedicado ao universo das aves. O catálogo reúne fotografias, nomes científicos e gravações para aproximar o visitante de diferentes espécies.

O objetivo é despertar a curiosidade pela natureza enquanto o site serve de laboratório para o aprendizado de desenvolvimento web. Explorar o catálogo, criar um perfil e registrar observações no feed são formas de experimentar o que está sendo construído.

02 / Quem está por trás

Aprender fazendo.

O responsável pelo repositório é Henri-pp09 no GitHub (abre em nova aba), estudante do curso Técnico em Desenvolvimento de Sistemas.

Seu portfólio reúne projetos, experimentos e aprendizados realizados durante a formação. Neste site, a prática envolve HTML semântico, estilos responsivos, JavaScript, APIs, armazenamento de dados e organização de código com Git e GitHub.

03 / As ferramentas

Cada parte tem seu papel.

HTML5 e CSS3
Estrutura das páginas, identidade visual e adaptação a diferentes tamanhos de tela.
JavaScript
Interações do catálogo, reprodução de áudio, formulários e publicações.
API do iNaturalist
Consulta de fotografias das espécies, com imagens locais como alternativa quando a consulta falha.
Armazenamento no navegador
Perfis, favoritos e publicações desta versão ficam salvos localmente no navegador utilizado. Não são sincronizados entre dispositivos.
Git e GitHub
Histórico de alterações, organização do portfólio e acompanhamento das próximas melhorias.
